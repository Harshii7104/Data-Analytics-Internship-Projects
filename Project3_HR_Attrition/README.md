# HR Employee Attrition Prediction

## Objective
Predict employees likely to leave the company using machine learning.

## Tools Used
- Python
- Pandas
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
IBM HR Analytics Employee Attrition Dataset

## Project Files
- HR_Attrition_Analysis.ipynb
- Dataset CSV
- Report PDF

## Key Insights
- Low salary employees leave more
- Some departments have higher attrition
- New employees leave faster
