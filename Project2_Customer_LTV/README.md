# 📊 Customer Lifetime Value & Churn Analysis

## 📌 Project Overview

This project analyzes customer behavior using an e-commerce dataset to understand customer value and predict churn.

## 🎯 Objectives

* Analyze customer purchasing behavior
* Segment customers based on value
* Predict customer churn using machine learning

## 🛠 Tools Used

* Python (Pandas, NumPy)
* Seaborn & Matplotlib
* Scikit-learn

## 📊 Key Features

* Customer segmentation (High, Medium, Low)
* Lifetime Value analysis
* Churn prediction using Logistic Regression

## 📈 Results

* Identified high-value customers
* Built a predictive model for churn
* Generated insights for business decision-making

## 📁 Files Included

* Notebook (.ipynb)
* Output dataset (.csv)
* Project report (.pdf)

## 🚀 Conclusion

This project helps businesses retain valuable customers and improve revenue through data-driven insights.
